# Momentum Association - web

- `index.html` - stránka
- `css/style.css` - vzhled
- `js/data.js` - sem se přidávají příležitosti, projekty a dokončené projekty (jediný soubor, který se běžně mění)
- `js/main.js` - logika stránky
- `images/` - loga, fotky projektů dávej do `images/projects/<slug>/`
- `reports/` - PDF reporty

Nový záznam: v `js/data.js` přidej položku do `opportunities`, `projects` nebo `reports`, nahraj fotky a PDF do složek a uveď cesty v polích `photos` a `report`.
